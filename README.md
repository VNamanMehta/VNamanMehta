- 💼 &nbsp;**Associate Software Developer at [Talview](https://www.talview.com/)** — building desktop applications with **Electron.js, React, and TypeScript**
- ⚡ &nbsp;Currently building **NOVA** — a hotkey-summonable AI assistant that lives a keystroke away and performs desktop automations on demand.
- 🧠 &nbsp;I built a **GPT-style small language model** end-to-end — custom BPE tokenizer, decoder-only transformer (~9M params), a parallelized data pipeline, and checkpointed training on the TinyStories dataset.
- 🔎 &nbsp;I like making retrieval *actually* work — **multimodal RAG** over PDFs using CLIP embeddings, FAISS, LangChain, and Gemini for grounded answers over both text and images.
- 📦 &nbsp;I published **envanalyzer** on npm — an AST-based env-var analyzer whose cross-file data flow tracer partially resolves *dynamic* `process.env` accesses. I also enjoy the messy real-world stuff — gesture-based camera control, a FlappyBird-playing AI, and a semantic screenshot daemon.
- 💬 &nbsp;Ask me about **Electron, React, Python, PyTorch, tokenizers, RAG, or shipping GenAI into a real app**.
